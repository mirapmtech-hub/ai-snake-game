# Project Context: Snake Game & AI Practice

## Project Overview
This project is a transition from a pure learning workspace to an active development environment. It currently features a functional **Snake Game** implemented in Python, alongside an **AI Learning Roadmap**. The goal is to eventually integrate AI/ML concepts (like Reinforcement Learning) into the Snake game.
