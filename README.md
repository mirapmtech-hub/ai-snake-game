# Terminal Snake Game

A simple implementation of the classic Snake game that runs directly in your terminal using the Python `curses` library.

## Requirements

- Python 3.x (with `curses` module, which is standard on Unix/macOS)

## Installation

1. Clone or download this repository.
2. (Optional) No external dependencies are required.

## How to Play

Run the game using the following command:

```bash
python snake.py
```

- Use the **Arrow Keys** to control the snake.
- Eat the special characters (represented by `ACS_PI`) to grow.
- Avoid hitting the walls or your own tail!
- Press **q** to quit or follow on-screen instructions to restart after losing.
